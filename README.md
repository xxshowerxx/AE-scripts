# AE Scripts

一组面向 Adobe After Effects 的开源歌词排版脚本。仓库当前提供两套互相独立的工具：一套生成多人演唱分配画面，一套把 SRT 生成为居中滚动歌词。脚本均为单文件 JSX，不依赖第三方 AE 插件。

> 当前版本：`v0.9.0-beta`。建议先在项目副本中试用；脚本已做静态语法检查，但不同 AE 版本、语言界面和效果属性仍可能存在差异。

## 包含内容

| 文件 | 用途 | 输入 | 输出 |
| --- | --- | --- | --- |
| `LyricsDistributionGenerator.jsx` | 多人歌词分配、角色拼贴、标题色带、封面与频谱 | ASS，或在面板中标注 SRT/LRC | 新建可编辑合成、预合成、文本层、控制层和效果 |
| `SRT滚动歌词导入器.jsx` | 当前句居中、相邻句淡化的滚动歌词 | UTF-8 SRT | 写入当前选中合成的文本、背景、字体样式和控制层 |
| `examples/example.ass` | 多人分配演示 | 原创占位内容，角色仅使用 A/B | 可直接用于熟悉 Actor 与分组规则 |
| `examples/example.srt` | 滚动歌词演示 | 原创双语占位内容 | 可直接测试导入流程 |

## 安装

### 推荐：安装为可停靠面板

1. 关闭 After Effects。
2. 将需要的 `.jsx` 文件复制到 AE 安装目录下的 `Scripts/ScriptUI Panels`。
3. 重启 AE。
4. 从“窗口”菜单打开对应脚本：`Lyrics Distribution Generator` 或 `SRT 滚动歌词导入器`。
5. 面板可以停靠、缩放，并与工程一起布置工作区。

常见目录示例：

- Windows：`Adobe After Effects <版本>/Support Files/Scripts/ScriptUI Panels/`
- macOS：`Adobe After Effects <版本>/Scripts/ScriptUI Panels/`

### 临时运行

也可以使用“文件 → 脚本 → 运行脚本文件”，选择 JSX。临时运行时会显示为浮动窗口。

多人分配工具在导出 ASS 或访问素材时需要文件权限。若文件选择或写入失败，请在“首选项 → 脚本和表达式”中启用“允许脚本写入文件和访问网络”。滚动歌词工具只读取用户主动选择的 SRT，通常无需写文件权限。

## 快速开始：多人歌词分配

### 1. 准备输入

最直接的方式是准备 ASS，并在 `[Events]` 的 `Name`/`Actor` 字段写出演唱者：

```text
A       A 独唱
A+B     A 与 B 合唱
ALL     当前项目中的全部角色
NONE    无人演唱
```

主、副歌词由面板中的 Style 下拉框指定，不要求 Style 必须叫 `MAIN`、`SUB`、`JP` 或 `CN`。

没有 ASS 时，可以先在“角色”页创建 A、B 等项目角色，再到“字幕标注”页导入 SRT/LRC。SRT 第一行会作为主歌词，其余行作为副歌词；LRC 当前按单行主歌词导入，缺失的结束时间由下一句开始时间推算，最后一句默认持续 4 秒。

### 2. 读取与标注

1. 在“项目”页选择 ASS、歌曲音频和可选背景，然后点击“读取 ASS 并识别角色”。
2. 在“角色”页检查角色顺序、显示名、主题色、图片、缩放和偏移。
3. 在“字幕标注”页逐句调整开始/结束时间、主副歌词与 Actor。
4. 使用角色复选框多选演唱者；“全选”写入 `ALL`，“清空”写入 `NONE`。
5. 点击“应用标注并载入项目”，或“导出 ASS”留作以后使用。

示例文件只使用 A、B 等匿名角色。请为自己的项目替换显示名、图片和颜色。

### 3. 句内切换与同一行分组

同一句中不同片段由不同角色演唱时，在文本里加入标记：

```text
[A]前半句[B]后半句
[A]独唱片段[B+C]多人片段
```

标记不会显示在成片中。各片段使用对应角色的实色色块；多人片段会按参与角色分色。

若几个不同时间段需要一直拼在同一行，为它们设置相同的“同一行组”：

```text
01.00–03.00  Actor=A  组=G1  文本=同一行的前半段
03.00–05.00  Actor=B  组=G1  文本=与后半段
```

整行会在 01.00–05.00 保持显示，角色图片、角色名和标题条则在 03.00 切换。分组以 `LDG_GROUP` 写入 ASS 的 Effect 字段，重新导入后仍可编辑。

“字符切分”可以把一句按字符边界和记录时间拆成多个同一行片段。“AE 预听”会建立或复用 `AUTO_SUBTITLE_AUDIO_PREVIEW` 合成；在 AE 时间线定位后点“记录当前时间”，再回到字符切分窗口使用这些时间点。ScriptUI 无法嵌入 Aegisub 式波形，因此定位依赖 AE 自身预览和时间线。

### 4. 角色与布局

- 支持任意数量角色、顶部拼贴和卡片横排。
- 每个角色可设置 Actor ID、两行显示名、主题色、图片、缩放和 X/Y 偏移。
- “永久保存角色样式”使用 AE 自身设置存储；识别到同名 Actor 时会自动套用。
- 未演唱角色可灰化、暗化并保持与下方标题色带连贯。
- 独唱、多人、ALL 和 NONE 状态分别驱动角色明暗、姓名、歌词与色带。
- 默认 1920×1080 顶部拼贴高度为 540。

### 5. 歌词、标题色带与颜色

- 主、副歌词可分别设置字体、字号、最小字号、位置和颜色。
- 过长文本会自动缩小到设定的最小字号。
- 支持 Scale + Fade、纯淡入淡出和无动画。
- 支持描边、统一阴影与角色色跟随。
- 多人及 ALL 可选择角色颜色、自定义渐变或固定色。
- 标题条高度会根据文字字号和留白计算；文字为空时缩成细色带。
- 上方常态阴影、下方阴影与当前演唱者增强阴影可分别配置。

### 6. 频谱与封面

内置频谱会创建“音频频谱 → 最小/最大 → 亮度和对比度 → 镜像”效果链，并自动指向当前歌曲。可设置频率范围、频段数、最大高度、持续时间、厚度、柔和度、颜色、位置、宽度、对比度、镜像和单/双向显示。

也可选择外部 AEP，填写其中的频谱合成名与音频占位层名。模板合成应为透明背景，频谱效果应引用该占位层。

封面可使用文字标题、Logo 或两者组合，并可在主合成首句开始前显示同一标题区。Logo 为图片；标题字体和颜色只作用于文字。

### 7. 生成后统一修改

主合成顶部会保留：

- `AUTO_CONTROLS`：主副歌词字号、X/Y、描边、字距、总透明度、总缩放，以及歌词/角色名阴影。
- `AUTO_FONT_MAIN_STYLE`：在字符面板修改主歌词字体。
- `AUTO_FONT_SUB_STYLE`：在字符面板修改副歌词字体。
- `AUTO_PROJECT_DATA`：禁用的恢复数据文本层。

字幕时间、Actor、句内切分、同一行组、角色数量、排版模式、自动换行结果、合成尺寸或素材替换会改变图层结构，需要从选中合成恢复到面板后重新生成。恢复操作默认生成新合成，不覆盖原合成。

## 快速开始：SRT 滚动歌词

1. 打开并选中要写入歌词的合成。
2. 打开 `SRT 滚动歌词导入器` 面板。
3. 在“项目”页选择 UTF-8 `.srt`；面板会显示读取条数和时间范围。
4. 在“歌词”页设置字体、字号、颜色和描边。
5. 在“布局/动画”页设置中心位置、行距、滚动时长、可见相邻句数、透明度和缩放。
6. 在“背景/效果”页设置阴影、当前句发光、圆角背景、边框和边框发光。
7. 点击“生成到当前合成”。如果字幕超出合成时长，可选择自动延长。

每个 SRT 字幕块生成一个文本层，多行内容会保留，因此可以直接做双语滚动歌词。当前句居中并高亮，相邻句按设置显示，其他句隐藏。第一句前和最后一句结束后全部歌词隐藏。

生成后会得到：

- `AUTO_SCROLL_CONTROLS`：位置、行距、字号、颜色、描边、相邻句数量、透明度、缩放、背景、边框、发光和阴影的统一控制。
- `AUTO_FONT_STYLE`：在字符面板替换全部歌词字体。
- `AUTO_SRT_###`：歌词文本层。
- `AUTO_SRT_BG_###`：可选的当前句背景层。

“滚动秒”决定生成时关键帧的提前量，修改后需要重新生成；其他视觉参数均可在控制层继续调整。面板的“保存当前为默认”只保存样式和布局，不保存字幕路径或项目内容。

## 字幕格式说明

SRT 时间行支持逗号或点作为毫秒分隔符：

```srt
1
00:00:01,000 --> 00:00:04,000
第一行
Second line
```

文件应使用 UTF-8。无效时间块、空文本块或结束时间不晚于开始时间的块会被跳过。

多人分配工具读取 ASS `[Events]` 中的时间、Style、Name/Actor、Effect 和 Text；会清理常见 ASS 样式标签，但当前不会解析 `\k` 卡拉 OK 音节。

## 默认配置与字体

两套面板都能“保存当前为默认”和“恢复出厂默认”。默认值存储在 AE 自身设置中，不写入仓库，也不包含当前字幕和项目素材。

AE 24.6 及以上可枚举字体并搜索；旧版本仍可手动输入 PostScript 字体名。字体缺失或名称无效时 AE 会回退到本机可用字体，因此跨平台共享工程前应检查排版。仓库没有捆绑字体。

## 隐私与公开发布前检查

脚本不会上传文件或遥测。素材由用户在本机选择，生成结果保存在当前 AE 工程。

需要特别注意：多人分配工具的 `AUTO_PROJECT_DATA` 为恢复编辑而记录所选素材的绝对路径。它可能包含用户名、盘符和目录结构。分享 `.aep/.aepx` 前，请删除该禁用文本层；删除后不会影响已经生成的画面，但将无法再从该合成恢复面板数据。公开提交前也不要加入真实歌词、角色图片、音频、外部频谱工程、自动保存文件或个人预设。

仓库的 `.gitignore` 默认排除 AE 工程、音视频、缓存、编辑器配置与本地预设；`examples/` 只允许两个已审核的匿名示例。

## 兼容性与已知限制

- 面向 Adobe After Effects ExtendScript；未依赖第三方插件。
- 字体列表功能需要 AE 24.6 或更高版本。
- 尚未完成所有 AE 版本、Windows/macOS 与不同界面语言的矩阵测试。
- 某些内置效果在不同 AE 版本中属性顺序可能变化；若频谱或发光效果异常，请保留 AE 版本、系统、复现步骤和错误行号提交 Issue。
- 多人分配暂不支持 ASS `\k` 逐字卡拉 OK。
- ScriptUI 不提供内嵌音频波形编辑器。
- 脚本生成大量可编辑图层；长字幕或大量角色会增加工程体积和生成时间。
- Beta 阶段建议在工程副本中运行，并利用 AE 的撤销组回退一次生成。

## 验证建议

发布或改动脚本后，建议至少手动测试：

- 多人分配：ASS、SRT/LRC、2/5/8 人、独唱/多人/ALL/NONE、句内切换、同一行组、字符切分、封面、内建与外部频谱、从合成恢复。
- 滚动歌词：单语/双语 SRT、第一句从 0 秒开始、字幕超过合成时长、0/1/多条相邻句、关闭背景/阴影/发光，以及生成后统一控制。
- 两套脚本：字体缺失、无效文件、取消文件选择、未选合成和重复生成。
