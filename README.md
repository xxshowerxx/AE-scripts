# 个人 AE 脚本工具

个人制作和整理的 Adobe After Effects 小工具仓库。

## 当前仓库

### 多人歌词分配生成器

文件：[多人歌词分配生成器.jsx](多人歌词分配生成器.jsx)

适合制作多人合唱、角色分配类歌词视频。可以读取 ASS，也可以导入 SRT/LRC 后在脚本里标注角色。

主要功能：

- 设置 A、B、C 等任意数量的角色。
- 支持独唱、多人合唱、全员合唱和无人演唱。
- 给不同角色设置图片、名称和代表色。
- 自动生成角色拼贴、歌词、标题色带和阴影。
- 支持一句歌词中途切换演唱角色。
- 支持几段歌词一直放在同一行显示。
- 可以生成简单的音频频谱和封面。
- 生成后仍可通过控制层统一修改字号、位置、描边、阴影等内容。
- 可以从生成过的合成中恢复设置，再生成一个新版本。

### 滚动字幕生成器

文件：[滚动字幕生成器.jsx](滚动字幕生成器.jsx)

适合制作“当前句在中间、上一句和下一句在旁边”的滚动歌词或字幕。

主要功能：

- 读取 UTF-8 编码的 SRT 字幕。
- 支持单行或双语多行字幕。
- 自动平滑滚动并突出当前句。
- 可设置字体、字号、颜色、描边和行距。
- 可调整当前句和相邻句的透明度、大小及显示数量。
- 可添加阴影、发光、圆角背景和边框。
- 可以保存自己的默认样式。
- 生成后可以通过统一控制层继续调整外观。

## 怎么安装

### 方法一：安装到 AE 窗口菜单

1. 关闭 After Effects。
2. 把需要的 `.jsx` 文件复制到 AE 安装目录中的 `Scripts/ScriptUI Panels` 文件夹。
3. 重新打开 AE。
4. 在 AE 顶部的“窗口”菜单中打开对应脚本。

安装后脚本可以像普通 AE 面板一样停靠和缩放。

### 方法二：直接运行

不想安装时，可以在 AE 中选择：

```text
文件 → 脚本 → 运行脚本文件
```

然后选择对应的 `.jsx` 文件即可。

如果脚本无法选择或写入文件，请在 AE 的“首选项 → 脚本和表达式”中打开“允许脚本写入文件和访问网络”。脚本本身不会上传文件。

## 快速使用：多人歌词分配生成器

最简单的流程：

1. 打开脚本。
2. 在“项目”页选择字幕、歌曲和可选的背景图片。
3. 读取 ASS，或者到“字幕标注”页导入 SRT/LRC。
4. 在“角色”页添加 A、B、C 等角色，并设置图片、名字和颜色。
5. 检查歌词、布局、颜色、封面和频谱设置。
6. 点击“生成 AE 合成”。

仓库中有一个不包含真实人物和歌词的示例：[examples/example.ass](examples/example.ass)。

### ASS 里的角色怎么写

在 ASS 的 `Name` 或 `Actor` 位置填写：

```text
A       A 独唱
B       B 独唱
A+B     A 和 B 合唱
ALL     所有角色合唱
NONE    没有人演唱
```

角色只是代号，实际显示名称可以在脚本中另外设置。

### 一句歌词中途切换

可以直接在歌词中加入角色标记：

```text
[A]前半句[B]后半句
[A]独唱部分[B+C]合唱部分
```

### 几段歌词放在同一行

如果不同时间的几段文字需要一直拼在同一行，可以给它们设置相同的“同一行组”。例如第一段由 A 演唱，第二段由 B 演唱，但画面始终显示完整的一行。

也可以使用“字符切分”功能，把一句话按照时间点拆成几段。

### 生成后怎么改

生成的主合成顶部会有几个以 `AUTO_` 开头的控制层。常用的是：

- `AUTO_CONTROLS`：统一修改歌词大小、位置、描边、阴影、透明度和缩放。
- `AUTO_FONT_MAIN_STYLE`：修改主歌词字体。
- `AUTO_FONT_SUB_STYLE`：修改副歌词字体。

如果要修改字幕时间、角色数量、演唱分配或整体排版，需要从合成恢复设置后重新生成。

## 快速使用：滚动字幕生成器

1. 在 AE 中打开并选中目标合成。
2. 打开“滚动字幕生成器”。
3. 在“项目”页选择 SRT 文件。
4. 在其他页面调整文字、位置、滚动和背景效果。
5. 点击“生成到当前合成”。

可以先用仓库中的 [examples/example.srt](examples/example.srt) 测试。

生成后：

- `AUTO_SCROLL_CONTROLS` 用于统一修改外观。
- `AUTO_FONT_STYLE` 用于替换全部字幕的字体。
- `AUTO_SRT_` 开头的是字幕文字层。
- `AUTO_SRT_BG_` 开头的是当前句背景层。

“滚动秒”会影响关键帧时间，修改它以后需要重新生成。其他大部分外观参数都可以直接在控制层中继续调整。

## 字幕文件小提示

- 建议使用 UTF-8 编码。
- SRT 的每一段可以有多行文字，因此可以放双语歌词。
- 多人脚本目前不会读取 ASS 的 `\k` 逐字卡拉 OK 标签。
- 字体在其他电脑上不存在时，AE 会自动换成可用字体，排版可能发生变化。

## 目前的情况

- 两个脚本都不需要第三方 AE 插件。
- 字体选择列表需要较新的 AE 版本；旧版本可以手动输入字体名。
- 目前还没有在所有 AE 版本和不同系统上测试。
- 如果字幕很多、人物很多，生成的图层也会比较多。
- 建议先保存工程，再运行脚本。
